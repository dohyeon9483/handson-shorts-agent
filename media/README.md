# media — 샘플 영상과 자막 시각

노션의 `노션배포_실습샘플_원본3종.zip`을 받아 MP4·VTT·words.json을 이 폴더에 함께 둡니다. 에이전트에게 ZIP을 찾아 풀어 달라고 해도 됩니다. 영상별 파일명 stem이 같아야 합니다.

VTT는 내용·문장 시각, words.json은 미리 STT로 만든 낱말 시각입니다. 배포 샘플은 STT를 다시 실행하지 않습니다. 에이전트가 GitHub의 지침·스킬·도구로 대표 프레임·장면 지도·편집안·spec·결과 영상을 새로 만듭니다. 원본과 자막은 읽기 전용입니다.

본인 영상도 사용할 수 있습니다. 자막이 없으면 사전 준비 단계에서 STT 도구로 work/에 생성합니다. VTT만으로도 문장 자막은 가능하지만 정확한 낱말 강조에는 STT 낱말 시각이 필요합니다. 대표 양식 이미지는 docs/styles/에 있습니다.

샘플 영상·실제 자막·강사 이미지는 공개 레포에 포함하지 않습니다. 제공된 샘플과 결과물은 세미나 실습 범위에서만 사용합니다.
