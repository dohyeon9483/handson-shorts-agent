# 가로 spec — 나이트 / 이러닝

`src`, `out`, 자막의 `words` 경로는 spec 파일 기준이다. t0/t1은 원본에서 추출할 구간이며 30초 이하로 한다. effects의 t0/t1은 **추출 시작점 기준**이다. 장면 지도와 words.json의 원본 시각에서 추출 시작점을 빼야 한다. subs 효과에는 `offset`을 spec의 t0와 같은 값으로 명시해 낱말 시각을 당긴다. words 원본 자체는 바꾸지 않는다.

```json
{
  "src": "../media/선택한원본.mp4",
  "out": "../out/가로실습.mp4",
  "t0": 10,
  "t1": 30,
  "theme": "night",
  "effects": [
    {"type": "caption", "t0": 0, "t1": 5, "html": "핵심 문장", "x": 960, "y": 180}
  ]
}
```

3번 양식은 theme을 elearn으로 한다. 화면과 실제 발언을 보고 문구·위치를 정한다. 처음에는 연속 구간과 최소한의 강조로 시작한다.

```text
python tools/landscape.py work/가로실습.json --preview --at 1 10 19
python tools/landscape.py work/가로실습.json --plan 가로실습_계획서.md
```

두 번째 명령은 승인 뒤에만 실행한다. 계획서는 spec과 같은 work/에 놓으면 위 경로로 연결된다. 계획서에는 해당 spec, 구간, 효과 문구, 미리보기 경로와 `상태: 검토중`을 적고, 참가자가 미리보기를 승인하면 `상태: 승인`으로 바꾼다. 계획서 파일만 존재하는 것은 승인이 아니다. 승인 뒤 spec에 큰 변경이 있으면 다시 확인한다.

미리보기 시각은 추출 시작점 기준이다. 여러 시각을 주면 한 JPG에 세로로 쌓는다. 효과는 움직이는 도중 글자가 비어 있을 수 있으므로 충분히 나타난 시점도 확인한다.

## 원본에 이미 틀이 있는 영상 (모두팝·CES 같은 행사 녹화)

로고·후원 띠·발표 화면 틀이 원본에 박혀 있으면 기본 위치가 그 위에 겹친다(2026-10-15 실측: 모두팝에 elearn 기본값을 쓰면 배지가 원본 로고, 위치표시가 슬라이드 제목, 말자막이 아래 띠를 덮었다).
- `badge`·`crumb` 는 넣지 않는다(원본에 이미 행사·과정 표시가 있다).
- `subs` 는 아래 띠 위로: 모두팝 B `"bottom": 150` 안팎, CES C `"bottom": 400` 안팎. 미리보기로 띠와 겹치지 않는지 본다.
- `feature`·`def` 는 슬라이드·무대의 빈 곳에. 강사(B 오른쪽 아래 창, C 무대 오른쪽 연사)를 가리지 않는다.
- `reframe` 은 강사가 화면 가운데 있는 촬영본(A)에 맞춘 효과다. B·C에서는 쓰지 않는다.
- 세로 쇼츠 크롭: C CES `{"cx": 900, "cy": 0, "cw": 580}`(연사 가운데, 미리보기 확인값). A의 값을 복사하지 않는다.
