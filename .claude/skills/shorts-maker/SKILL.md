# 대표 양식 4종으로 영상 만들기

먼저 AGENTS.md를 읽는다. 원본 정보가 없으면 tools/prepare_video.py로 대표 프레임을 준비하고 work/에 장면 지도를 작성한다. 배포 샘플의 VTT·words.json을 재사용해 STT 비용을 들이지 않는다. 본인 영상에 자막이 없거나 VTT만 있고 낱말 강조가 필요하면 사전 준비에서 STT를 실행한다. 별도의 비공개 스킬이나 샘플 설계도를 요구하지 않는다. 원본과 양식은 서로 독립적인 선택이다. docs/styles/index.html과 1.jpg~4.jpg를 열어 양식 선택을 받는다. 참가자가 이미 골랐다면 진행한다. 기획안은 기본 하나다.

## 공통

선택한 원본의 work/sources/<이름_해시>/source.json에서 VTT·words.json 경로를 찾아 읽고, work/의 장면 지도를 읽는다. 기존 자막이 있으면 source.json이 가리키는 media/의 읽기 전용 파일을 쓴다. 원본 A의 교정표·주제·얼굴 좌표를 B에 적용하지 않는다. 배포된 B의 시각은 추출본 기준이며 전체 원본 시각은 출처 기록에만 쓴다. 문장 경계에서 20~30초를 고르고 work/<이름>.json에 판단을 모은다. 원본은 수정하지 않는다.

편집안에 원본·양식 번호·화면 비율·사용 구간·제목·총길이를 명시한다. 시작·중간·끝의 실제 미리보기를 열어 보여 준다. 얼굴과 원본 자막·슬라이드 가림을 확인한다. 선택한 한 편의 렌더만 참가자 승인 뒤 실행한다. 결과 MP4의 비율·길이·음성을 확인한다. 수정은 spec에서 한다.

## 1·3번: 가로

`tools/landscape.py --help`로 실제 옵션을 확인한다. 기존 fx.py 스키마인 src/out/t0/t1/theme/effects를 쓴다. 1번은 night, 3번은 elearn. 경로는 spec 기준 상대경로다. 1920×1080, t1-t0 <=30초. 효과 시각은 추출 시작점 기준이므로 원본 시각과 혼동하지 않는다.

렌더 전 계획서에는 구간·문구·효과·미리보기 경로와 상태를 적는다. 참가자가 승인해야 `상태: 승인`을 기록한다. 렌더 명령의 --plan에 계획서를 넘긴다. 실제 스키마는 같은 폴더의 [가로 spec 참고](references/landscape-spec.md)를 읽는다.

## 2·4번: 세로

`tools/shorts.py work/<이름>.json --preview`로 미리보기를 만든다. spec 상세는 [쇼츠 spec 레퍼런스](references/shorts-spec.md)를 읽는다. 2번은 style을 생략, 4번은 segment마다 style=cc. 좌표는 원본 화면 확인 후 정한다. 상단 제목·얼굴·말자막의 안전 영역을 지킨다.

참가자 승인 후 `python tools/shorts.py work/<이름>.json`으로 렌더한다. 급하면 --fps 15 또는 15~20초를 제안한다. 과한 효과를 줄이되 선택한 양식을 임의로 바꾸지 않는다. spec segments 길이의 합은 30초 이하여야 한다.

## 시간 부족·실패

환경 점검에서 실패한 항목을 알린다. 체크포인트가 없어도 스킬의 spec 형식으로 새로 작성한다. 자막이 없으면 준비 요청 범위에서 STT를 실행하고, 실패하면 원인과 미완료를 알린다. 전체 렌더를 못 끝내면 미리보기와 spec을 보관하고 미완료임을 알린다.

## 자막 정밀도

실제 words.json이 있을 때만 낱말별 강조를 사용한다. 2번은 현재 낱말 굵게, 4번은 상자 강조와 karaoke를 지원한다. VTT만 있으면 vtt 경로를 spec에 지정해 문장 단위 자막을 사용한다. 낱말 시각을 균등 분배하거나 추정해서 정확한 동기화라고 안내하지 않는다. 샘플 STT를 실습 중 다시 돌리지 않는다.
