# 강의 영상으로 쇼츠 만들기 — AI로 날개 피자 핸즈온 가이드

**이 문서 하나만 보면 됩니다.**
2분짜리 강의 영상을 AI 에이전트에게 맡겨 **세로 쇼츠(1080×1920)** 를 만듭니다.
코드는 쓰지 않습니다. **기획을 고르고, 결과를 보고, 고쳐 달라고 말하는 것**까지가 여러분 몫입니다.

```
강의 영상(가로) ─▶ 에이전트가 기획안 3개 ─▶ 고르기 ─▶ 미리보기 ─▶ 렌더 ─▶ "이렇게 고쳐 줘"
```

- 진행: **2인 1조 · 25분** · 조마다 Claude Code(또는 Codex)가 되는 노트북 1대
- 결과 영상은 레포의 `out/` 폴더에 생깁니다.

---

## 1. 받을 파일 (2개)

| # | 파일 | 받는 곳 | 어디에 두나 |
|---|---|---|---|
| ① | **이 레포** | 이 페이지의 초록 **Code** 버튼 → *Download ZIP* → 압축 풀기 | 아무 폴더(예: 바탕화면) |
| ② | **샘플 묶음** `노션배포_샘플묶음.zip` (30MB) | 노션 페이지 첨부 | **받은 그대로**(다운로드 폴더) 두면 됩니다 — 푸는 건 Claude 가 합니다 |

## 2. 미리 준비 (세미나 전, 15분) — 설치도 Claude 에게 맡깁니다

직접 하는 건 **세 가지**뿐입니다.

1. **Claude Code 데스크톱 앱**을 설치하고 로그인합니다(유료 계정). Codex 도 됩니다.
2. 위 **1장의 파일 2개**를 받습니다(레포는 압축을 풀고, 샘플 묶음은 받은 그대로).
3. Claude Code 에서 **레포 폴더**(README.md 가 보이는 곳)를 열고, 아래 문장을 그대로 보냅니다.

> **실습 준비를 해 줘. 다운로드 폴더에 있는 노션배포_샘플묶음.zip 을 media 폴더에 풀고, 필요한 걸 설치한 다음 환경 점검까지 해 줘.**

Claude 가 알아서 하는 일(5~10분): 샘플 묶음 풀기 → Python 확인(없으면 설치 방법 안내·설치) → 패키지·크로미움(150MB) 설치 → 점검.
중간에 "실행해도 될까요?" 하고 물으면 **허용(Allow)** 을 누르세요.

**끝났다는 신호**: Claude 가 점검 결과를 보여 주며 **"모두 ✅, 미리보기 시험 ✅"** 라고 말하면 준비 끝입니다.
❌ 가 남으면 Claude 의 안내를 따르거나, 그 화면을 캡처해 문의 채널에 올려 주세요.

> 당일 가장 많이 막히는 건 **로그인**과 **설치**입니다. 미리 해 오면 실습 시간을 온전히 쓸 수 있습니다.
> 직접 하고 싶은 분: `setup/setup_windows.ps1`(Windows) · `setup/setup_mac.sh`(Mac) 를 실행하면 같은 일을 합니다.

## 3. 당일 실습 (25분)

### 역할 나누기
- 🖐 **드라이버**: 키보드를 잡고 아래 문장을 보냅니다. Claude Code 가 "실행해도 될까요?" 하고 물으면 **허용(Allow)** 을 누릅니다. 렌더러를 돌리는 것이라 안전합니다.
- 🎬 **디렉터**: 기획안을 고르고 결과를 평가합니다. 이 문서의 4·5장을 옆에 띄워 둡니다.

### 순서 — 이 문장을 그대로 보내세요 (바꿔 말해도 됩니다)

| 시간 | 단계 | 보낼 말 | 끝났다는 신호 |
|---|---|---|---|
| 0~3분 | ① 자기소개 | **이 프로젝트는 뭐 하는 곳이야? 너는 어떤 에이전트고, 영상으로 어떤 편집을 할 수 있어?** | 영상팀 직무 표가 나옴 |
| 3~8분 | ② 기획안 | **샘플 영상으로 30초 안쪽 쇼츠를 만들고 싶어. 받아쓰기를 읽고 기획안 3개를 제안해 줘. 안마다 첫 문장(훅), 쓸 구간, 화면 배치를 알려 줘.** | 기획안 3개가 표로 나옴 |
| 8~10분 | ③ 만들기 | **2번 안으로 만들어 줘.** (시간이 빠듯하면 "기본형으로, 20초 안으로") | 미리보기 한 장 → 렌더 시작 |
| 렌더 중 | 설명 듣기 | — (기본형 20초 ≈ 2~4분 · 캡컷식 30초 ≈ 4~8분) | `out/` 에 mp4 가 생김 |
| 18~25분 | ④ 고치기 | 결과를 보고 **5장의 체크 5가지** 중 하나를 말하기 | 다시 렌더 시작 |

②에서 바꿔 말해 보기
- "20대 직장인이 끝까지 볼 만한 걸로"
- "강의 홍보용으로, 마지막에 본편 안내 넣어서"
- "캡컷처럼 효과 많이 들어간 버전도 하나"

직접 기획하고 싶으면 아래 칸을 채워 붙여 넣고 **"이 기획으로 만들어서 미리보기 보여 줘"** 라고 보냅니다.
```
[누가 보나]     예) 유튜브를 시작해 볼까 망설이는 30대 직장인
[한 줄 메시지]  예) 유튜브는 망해도 잃을 게 없다
[첫 3초 훅]     예) "월 천만 원, 연봉 1억. 처음엔 생각만 했습니다"
[쓸 장면·순서]  예) 장면 2 → 장면 3 → 장면 6   (아래 장면 지도 참고)
[스타일]        기본형 / 캡컷식
[길이]          20~30초
```

### 샘플 영상 장면 지도 (2:16)
| # | 장면 | 구간 | 내용 | 훅으로 쓸 만한 말 |
|---|---|---|---|---|
| 1 | 강사 소개 | 0:00–0:05 | 그루비스튜디오 대표 소개 | — |
| 2 | 떡상 경험 | 0:05–0:29 | 생각만 하다 시작 → 월 천만 원·연봉 1억 | "유튜브 한번 해 볼까? 생각해 보신 적 있죠?" |
| 3 | 왜 유튜브인가 | 0:29–0:51 | 초기 자본 0원, 망해도 잃을 게 없다 → 정산서 | "망해도 잃을 게 없습니다" |
| 4 | 솔직한 단점 | 0:51–1:18 | 수익은 일정하지 않다 → 그래도 상방이 열려 있다 | "솔직하게 말씀드리면…" |
| 5 | 강의 소개 | 1:18–1:54 | 편집 기술 강의가 아니다 → 기획·설계 → 10개 챕터 | "이 강의는 편집 기술 강의가 아닙니다" |
| 6 | 응원 | 1:54–2:16 | 벌어도 보고 잃어도 봤다 → 끝까지 | "벌어 봤고, 잃어도 봤고" |

## 4. 부탁할 수 있는 것 (말로 하면 됩니다)

| 분류 | 이렇게 말하면 |
|---|---|
| 화면 배치 | "강사 크게, 위에 제목" · "위에 그래픽, 아래 강사" · "그래프를 크게, 강사는 작은 원으로" |
| 글자 | "제목을 ○○로 / 더 짧게 / 질문으로" · "'0원'만 노랗게" · "자막을 더 크게" · "말하는 낱말을 초록 상자로" · "말한 만큼 노랗게 채워 줘" |
| 그래픽 | "정산서 보여 줘" · "들쭉날쭉한 막대그래프" · "스티커처럼 ○○ 띄워 줘" · "그 위에 빨간 ✕ 도장" · "숫자가 0부터 올라가게" · "1·2·3 목록으로" · "크게 '○○' 터뜨려 줘" · "이모지 🤔" · "구독 버튼이랑 화살표" |
| 움직임·소리 | "첫 장면을 확 당겨 줘" · "천천히 밀고 들어가게" · "'아닙니다'에서 화면 흔들어 줘" · "반전에 글리치랑 번쩍" · "효과음 넣어 줘(뿅·팝·땡·두둥·딩·슉)" |
| 순서·길이 | "결론부터 보여 줘" · "20초 안으로" · "1:38~1:44 를 넣어 줘" |
| 지금 안 됨 | 배경 지우기, 얼굴·목소리 합성, 배경 음악, 샘플에 없는 외부 영상 |

숫자·정산서·그래프는 실제 자료가 아니라 **예시**이며, 화면에 '예시'가 표시됩니다.

## 5. 결과 체크 5가지 → 이렇게 고쳐 달라고 하기

| # | 볼 것 | 아니면 이렇게 말하기 |
|---|---|---|
| 1 | 첫 3초에 무슨 내용인지 알겠다 | "첫 3초를 숫자로 시작하게 바꿔 줘" |
| 2 | 3초 넘게 심심한 곳이 없다 | "10초쯤에 확대나 스티커 하나 넣어 줘" |
| 3 | 얼굴이 가려지지 않는다 | "자막이 얼굴을 가려, 위로 올려 줘" |
| 4 | 제목이 한눈에 읽힌다 | "제목을 한 줄로 줄여 줘" |
| 5 | 끝이 깔끔하다 | "마지막에 본편 안내 버튼 넣어 줘" |

더 화려하게: **"캡컷처럼 확대랑 효과음 넣어 줘"** · 비교: **"예시 02(캡컷식) 렌더해서 내 거랑 비교해 줘"**

## 6. 막힐 때

| 증상 | 해결 |
|---|---|
| 준비가 안 끝남 / ❌ 가 남음 | **"점검에서 ❌ 가 난 걸 고쳐 줘"** |
| Python 을 설치했는데도 못 찾음 | Claude Code 를 껐다 켠 뒤 **"다시 점검해 줘"** (설치 직후엔 새로 열어야 보임) |
| 회사 보안 PC 라 설치가 막힘 | 개인 노트북으로 바꾸거나 옆 조와 합치기 |
| Claude Code 가 계속 허락을 물음 | 매번 **허용**(같은 명령은 "항상 허용"도 됨) |
| Claude Code 가 파일을 못 찾음 | README.md 가 보이는 레포 폴더 **안**을 열었는지 확인 |
| 렌더가 너무 느림 | **"빠르게 다시 렌더해 줘"** / **"구간을 2개로 줄여 줘"** |
| 시간이 거의 없음 | **"체크포인트를 그대로 렌더해 줘"** → 결과를 보고 고치기 |
| 오류가 남 | **"오류를 읽고 고쳐 줘"** |
| 그래도 안 됨 | 옆 조와 합치거나 진행자 PC 로 렌더 |

## 7. 세미나 뒤 — 내 영상으로 해 보기 (선택)

1. 받아쓰기 도구를 설치합니다(처음 한 번): `pip install -r requirements-transcribe.txt`
2. 가로 영상을 `media/` 에 넣습니다. 예: `media/내강의.mp4` (이름은 짧게, 띄어쓰기 없이)
3. Claude Code 에 **"media/내강의.mp4 받아쓰기 만들어 줘"** 라고 보냅니다(직접 하려면 `python tools/transcribe.py media/내강의.mp4`).
4. 받아쓰기는 사람 이름·제품명을 잘 틀립니다 → **"받아쓰기에서 '○○'는 '○○'가 맞아"**
5. 그다음은 3장과 같습니다. **"이 영상으로 30초 쇼츠 기획안 3개 줘"**

> 화면 배치 기본값은 '강사 1명, 정면, 가운데'에 맞춰져 있습니다. 강사가 한쪽에 있으면 "강사가 오른쪽에 있어"라고 알려 주세요. 세로로 찍은 영상은 다루지 않습니다.

## 사용 범위
- 샘플 영상은 강사의 동의를 받아 **이 세미나 실습용으로만** 노션으로 나눕니다(이 레포에는 없음). 영상과 결과물을 외부(SNS·유튜브 등)에 올리지 마세요.
- 효과음은 코드로 직접 만든 소리이고, 글꼴은 상업 이용 가능한 무료 글꼴(Pretendard·G마켓 산스·East Sea Dokdo·Noto Color Emoji)입니다.
- 렌더러는 모두의연구소 강의 영상 제작 작업장의 `lecture-effects` 스킬(2026-10)에서 쇼츠 부분만 떼어 노트북용으로 고친 것입니다.
