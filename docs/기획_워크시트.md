# 쇼츠 기획 워크시트 (선택)

에이전트의 기획안이 마음에 안 들면, 디렉터가 이 칸을 채워서 그대로 붙여 넣으세요.
`media/장면지도.md`(노션 묶음)를 옆에 띄워 두면 빠릅니다.

```
[누가 보나]      예) 유튜브를 시작해 볼까 망설이는 30대 직장인
[한 줄 메시지]   예) 유튜브는 망해도 잃을 게 없다
[첫 3초 훅]      예) "월 천만 원, 연봉 1억. 처음엔 생각만 했습니다"
[쓸 장면·순서]   예) 장면 2(15초~22초) → 장면 3(32초~37초) → 장면 6(114초~119초)
[스타일]         기본형 / 캡컷식
[꼭 넣을 것]     예) 숫자 크게, 마지막에 본편 안내
[길이]           20~30초
```

붙여 넣을 때: **"이 기획으로 spec 만들어서 미리보기 보여 줘"**

## 좋은 쇼츠 체크 5가지 — 결과를 볼 때

| # | 볼 것 | 아니면 이렇게 말하기 |
|---|---|---|
| 1 | 첫 3초에 무슨 내용인지 알겠다 | "첫 3초를 숫자(또는 질문)로 시작하게 바꿔 줘" |
| 2 | 3초 넘게 아무것도 안 바뀌는 곳이 없다 | "○초쯤이 심심해. 확대나 스티커 하나 넣어 줘" |
| 3 | 얼굴이 가려지지 않는다 | "자막(스티커)이 얼굴을 가려. 위로 올려 줘" |
| 4 | 제목이 한눈에 읽힌다(두 줄, 줄당 10자 안팎) | "제목을 한 줄로 줄여 줘" |
| 5 | 끝이 깔끔하다(결론·본편 안내·첫 질문으로 돌아감) | "마지막에 본편 안내 버튼 넣어 줘" |
