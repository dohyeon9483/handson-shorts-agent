# 세미나 뒤 — 내 영상으로 쇼츠 만들기

실습 샘플은 받아쓰기가 미리 들어 있었습니다. 내 영상은 **받아쓰기를 먼저 만들면** 같은 방법으로 됩니다.

## 1. 받아쓰기 도구 설치 (처음 한 번)
```bash
pip install -r requirements-transcribe.txt
```
처음 받아 쓸 때 음성 인식 모델(small, 약 500MB)을 내려받습니다.

## 2. 영상 넣고 받아쓰기
1. 가로 영상(mp4)을 `media/` 에 넣습니다. 파일 이름은 짧게, 띄어쓰기 없이 하세요. 예: `media/내강의.mp4`
2. 받아쓰기를 만듭니다.
   ```bash
   python tools/transcribe.py media/내강의.mp4          # CPU · 2분 영상에 1~3분
   python tools/transcribe.py media/내강의.mp4 --gpu    # NVIDIA GPU 가 있으면(안 되면 CPU 로 다시)
   ```
   → `media/내강의.vtt`(문장), `media/내강의.words.json`(낱말 시각)

   또는 에이전트에게: **"media/내강의.mp4 받아쓰기 만들어 줘"**

## 3. 틀린 말 고치기
받아쓰기는 **사람 이름·회사명·제품명**을 자주 틀립니다. `.vtt` 를 훑어보고 에이전트에게 말하세요.
> "받아쓰기에서 '홍길똥'은 '홍길동'이 맞아. 교정표에 넣어 줘."

## 4. 나머지는 실습과 같습니다
> "media/내강의.mp4 로 30초 쇼츠 기획안 3개 줘" → "2번으로 만들어 줘" → "이렇게 고쳐 줘"

## 알아 둘 것
- **화면 배치 기본값은 '강사 1명, 정면, 가운데'인 영상에 맞춰져 있습니다.** 강사가 한쪽에 있거나 화면 녹화라면 에이전트에게 "강사가 화면 오른쪽에 있어" / "화면 녹화 영상이야"라고 알려 주세요. 미리보기를 보고 자르는 위치를 맞춥니다.
- 세로로 찍은 영상은 지금 렌더러가 다루지 않습니다(가로 → 세로 전용).
- 다른 사람이 나오는 영상은 그 사람의 동의를 받고 쓰세요. 배경 음악·외부 영상에는 저작권이 있습니다.
