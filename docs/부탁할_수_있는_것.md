# 부탁할 수 있는 것 — 메뉴판

에이전트에게 **이 표의 말 그대로** 부탁하면 됩니다. 이름(괄호 안)은 몰라도 됩니다.
여기 없는 것도 일단 말해 보세요. 안 되면 에이전트가 안 된다고 하거나 비슷한 것을 제안합니다.

## 화면 배치 — 구간마다 하나

| 이렇게 말하면 | 화면 | 어울리는 장면 |
|---|---|---|
| "강사 크게, 위에 제목" | 위에 큰 제목, 아래에 강사 (`speaker`) | 훅, 결론, 대부분 |
| "위에 그래픽, 아래 강사" | 화면을 위아래로 나눔 (`split`) | 정산서·자료를 보여 줄 때 |
| "그래프를 크게, 강사는 작은 원으로" | 그래픽이 화면을 채우고 강사는 원형 창 (`board`) | 숫자·그래프 |

## 글자

| 이렇게 말하면 | 무엇이 바뀌나 |
|---|---|
| "제목을 ○○로 바꿔 줘" / "더 짧게" / "질문으로" | 위쪽 큰 제목 |
| "'0원'만 노랗게" | 제목 안 강조 낱말 |
| "제목을 중간에 바꿔 줘(3초쯤)" | 한 구간 안에서 제목 교체 |
| "자막을 더 크게" / "한 줄에 더 적게" | 말자막 크기·글자 수 |
| "말하는 낱말을 초록 상자로" / "말한 만큼 노랗게 채워 줘" | 캡컷식 자막(상자형 / 노래방형) |
| "마지막에 본편 안내 버튼" | 끝 화면 노란 버튼 |

## 그래픽

| 이렇게 말하면 | 무엇이 들어가나 |
|---|---|
| "정산서를 보여 줘" | 금액이 흐린 문서 카드(‘예시 화면’ 표시 자동) |
| "들쭉날쭉한 막대그래프" | 막대그래프(‘예시’ 표시 자동) |
| "스티커처럼 ○○, ○○ 띄워 줘" | 흰 스티커 칩(이모지 가능) |
| "그 위에 빨간 ✕ 도장" | 쾅 찍히는 ✕ |
| "검색창처럼 보여 줘" | 검색창 모양 띠 |
| "숫자가 0부터 올라가게" | 숫자 슬롯(예: 0 → 10 챕터) |
| "1·2·3 목록으로, 말할 때마다 하나씩" | 리스트 카드(지금 항목이 노랗게) |
| "크게 '○○' 터뜨려 줘" | 큰 글자 + 폭발 도형 |
| "이모지 하나 넣어 줘 🤔" | 이모지 스티커 |
| "구독 버튼이랑 화살표" | 구독 스티커 + 손글씨 화살표 |

## 움직임·소리 (캡컷식)

| 이렇게 말하면 | 효과 |
|---|---|
| "첫 장면을 확 당겨 줘" | 즉시 확대(펀치인) |
| "천천히 밀고 들어가게" | 천천히 확대 |
| "'아닙니다'에서 화면 흔들어 줘" | 흔들림 |
| "반전 부분에 글리치랑 번쩍" | 색 분리 글리치 + 흰 플래시 |
| "효과음 넣어 줘(뿅·팝·땡·두둥·딩·슉)" | 효과음(코드로 직접 만든 소리) |

## 순서·길이

| 이렇게 말하면 | 무엇이 바뀌나 |
|---|---|
| "결론부터 보여 줘" | 구간 순서 바꾸기 |
| "20초 안으로" / "구간 하나 빼 줘" | 길이 줄이기(렌더도 빨라짐) |
| "1:38~1:44 를 넣어 줘" | 구간 직접 지정 |

## 지금은 안 되는 것
- 강사 배경 지우기(누끼), 다른 사람 얼굴·목소리 합성
- 배경 음악 깔기(저작권 때문에 넣지 않음)
- 샘플에 없는 외부 영상·이미지 가져오기(실습 범위 밖)
