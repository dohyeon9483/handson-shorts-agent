# 프롬프트 카드 — 2인 1조 · 25분

정답 문장은 없습니다. 원하는 걸 말하고, 결과를 보고, 아쉬운 점을 말하면 됩니다.

**역할 나누기**
- 🖐 **드라이버**: 키보드를 잡고 프롬프트를 보냅니다. Claude Code 가 "실행해도 될까요?" 하고 물으면 **허용(Allow)** 을 누릅니다.
- 🎬 **디렉터**: 기획안을 고르고 결과를 평가합니다. 옆에 `docs/부탁할_수_있는_것.md` 를 띄워 둡니다.

| 시간 | 단계 | 끝났다는 신호 |
|---|---|---|
| 0~3분 | ① 자기소개 | 에이전트가 직무 표를 보여 줌 |
| 3~8분 | ② 기획안 3개 | 표로 3안이 나옴 |
| 8~10분 | ③ 고르고 만들기 | 미리보기 한 장이 나오고 렌더가 시작됨 |
| (렌더 2~8분) | 진행자 설명 듣기 | `out/` 에 mp4 가 생김 |
| 18~25분 | ④ 고치기 한 번 | 다시 렌더 시작(시간 없으면 미리보기까지만) |

---

## ① 에이전트에게 자기소개 시키기
> 이 프로젝트는 뭐 하는 곳이야? 너는 어떤 에이전트고, 영상으로 어떤 편집을 할 수 있어? 편집 유형도 알려 줘.

👀 볼 것: 에이전트들이 **사람 직무**(속기사·편집자·모션 디자이너·검수자…)처럼 나뉘어 있다.

---

## ② 기획안 받기
> 샘플 영상으로 30초 안쪽 쇼츠를 만들고 싶어. 받아쓰기를 읽고 기획안 3개를 제안해 줘.
> 안마다 첫 문장(훅), 쓸 구간, 화면 배치를 알려 줘.

바꿔 말해 보기
- "20대 직장인이 끝까지 볼 만한 걸로"
- "강의 홍보용으로, 마지막에 본편 안내 넣어서"
- "캡컷처럼 효과 많이 들어간 버전도 하나"
- 직접 기획하고 싶으면 → `docs/기획_워크시트.md` 를 채워 붙여 넣기

---

## ③ 고르고 만들기
> 2번 안으로 만들어 줘.

👀 에이전트가 spec(설계도 한 장)을 쓰고 → **미리보기 한 장**을 먼저 보여 준 뒤 → 렌더합니다.
⏱ 기본형 20초 ≈ 2~4분, 캡컷식 30초 ≈ 4~8분(노트북 기준, 데스크톱은 절반쯤). **시간이 빠듯하면 "기본형으로, 20초 안으로"**.

---

## ④ 고쳐 달라고 하기 — 결과를 보고 체크 5가지

| 아쉬운 점 | 이렇게 말하기 |
|---|---|
| 첫 3초가 약하다 | "첫 3초를 숫자로 시작하게 바꿔 줘" |
| 중간이 심심하다 | "10초쯤에 확대나 스티커 하나 넣어 줘" |
| 얼굴을 가린다 | "자막이 얼굴을 가려, 위로 올려 줘" |
| 제목이 길다 | "제목을 한 줄로 줄여 줘" |
| 끝이 밋밋하다 | "마지막에 본편 안내 버튼 넣어 줘" |
| 더 화려하게 | "캡컷처럼 확대랑 효과음 넣어 줘" |

---

## 🆘 막혔을 때 한 마디
| 상황 | 이렇게 말하기 |
|---|---|
| 렌더가 너무 오래 걸림 | "빠르게 다시 렌더해 줘(--fps 15)" 또는 "구간을 2개로 줄여 줘" |
| 시간이 거의 없음 | "체크포인트를 그대로 렌더해 줘" |
| 오류가 남 | "오류를 읽고 고쳐 줘. 설치 문제면 check_env 결과를 보여 줘" |
| 결과 파일을 못 찾음 | "결과 영상 경로 알려 주고 폴더 열어 줘" |
